# صداهای موجود در سایت تولید صدا (aisada.ir)

فهرست صداهایی که می‌توان برای شخصیت‌ها انتخاب کرد (توصیف از خود سایت). **هر شخصیت همیشه با یک صدای ثابت** ضبط شود.

## صداهای مرد
شهاب (قدرتمند و رسا) • نوید (جوان و پرانرژی) • آرمان (گرم و صمیمی) • دانا (خبری و آموزنده) • سامان (شاداب و پویا) •
آرش (مطمئن و تاثیرگذار) • بهرام (حماسی و نافذ) • نیکان (مهربان و شیرین) • مانی (خلاق و متفاوت) • آرتین (با اصالت و شیک) •
امید (انگیزه‌بخش و مثبت) • بردیا (ورزشی و پرهیجان) • کامیار (مصمم و جدی) • کیانوش (درخشان و گیرا) • پویا (بازیگوش و سرزنده) • سام (جسور و بی‌باک)

## صداهای زن
آوا (لطیف و دلنشین) • مهسا (باوقار و رسمی) • شبنم (آرام و متین) • سحر (دوستانه و گیرا) • مریم (حرفه‌ای و واضح) •
فرناز (پخته و قابل اعتماد) • سارا (جذاب و مدرن) • دلنواز (هنری و احساسی) • روژان (شفاف و گویا) • ترانه (موزیکال و خوش‌آهنگ) •
نیکو (روایتگر و قصه‌گو) • هستی (طبیعی و خودمانی) • مهتاب (نجواگر و آرامش‌بخش) • لیدا (کلاسیک و باوقار)

## تخصیص فعلی (تغییر ندهید، مگر با ضبط دوباره‌ی همه‌ی خط‌های آن شخصیت)
| گوینده | صدا |
|---|---|
| راوی (معرفی، هدف، سرنخ) | نیکو |
| دانشنامه و پرسش‌ها | دانا |
| سیمرغ | مهتاب (جایگزین: دلنواز) |
| سام | بهرام |
| سنگ‌نوشته | شهاب |
| راهنمای تالار | آرتین |
| نگهبان دروازه (مرحله ۶) | کامیار (مصمم و جدی) |
| آرش کمانگیر (مرحله ۷) | آرش (مطمئن و تاثیرگذار) |

## پیشنهاد برای شخصیت‌های مراحل بعدی (هنوز در بازی نیستند)
| نقش احتمالی | صدای پیشنهادی |
|---|---|
| پهلوان یا راهنمای مسیر (آرش پیش‌تر برای آرش کمانگیر استفاده شده) | نوید (جوان و پرانرژی) یا بردیا (ورزشی و پرهیجان) |
| نگهبان یا کاروان‌سالار | کامیار (مصمم و جدی) |
| کودک همراه یا دوست بازیگوش | پویا (بازیگوش و سرزنده) |
| پیرمرد مهربان / قصه‌گوی روستا | نیکان (مهربان و شیرین) |
| بانوی حماسی (مثلاً برای داستان‌های بعدی) | لیدا (کلاسیک و باوقار) |
