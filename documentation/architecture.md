# معماری فنی

## فناوری پایه
- Godot 4.4.1 و GDScript
- Mobile renderer با سازگاری GL
- صحنه‌ها و سیستم‌های مستقل و قابل تست
- GitHub Actions برای import، اعتبارسنجی و خروجی Android

## ساختار توسعه
- `app/scenes`: صحنه‌های بازی و رابط
- `app/scripts`: منطق بازیکن، مأموریت، رابط و ذخیره
- `app/content`: داده‌های بسته‌های محتوایی داخل APK
- `content`: داده‌های مرجع و پژوهشی مستقل از موتور
- `backend`: در فازهای بعدی حساب کاربری، خرید، تحویل بسته و همگام‌سازی

## اصول معماری
1. Offline-first: شروع بازی و محتوای پایه بدون اینترنت در دسترس باشد.
2. شناسه پایدار برای هر شخصیت، مکان، مأموریت و مدخل آموزشی.
3. جداسازی داده از منطق بازی؛ محتوای جدید بدون بازنویسی سیستم‌ها اضافه شود.
4. سیستم پرداخت مستقل از رابط و قابل اتصال به فروشگاه‌های ایرانی.
5. پیشرفت محلی در MVP؛ همگام‌سازی حساب در مرحله بعد.
6. دارایی‌های حجیم با Git LFS یا فضای توزیع جداگانه مدیریت شوند.

## عملکرد موبایل
محیط محدود، LOD، کاهش جزئیات اشیای دور، محدودکردن سایه‌ها و نورهای پویا، پروفایل کیفیت و تست روی گوشی واقعی از ابتدا لحاظ شوند. موفقیت build به‌تنهایی عملکرد مناسب را ثابت نمی‌کند.

## امنیت
کلید امضا، رمزها، توکن‌ها و اسرار backend نباید در مخزن عمومی قرار گیرند. برای انتشار امضاشده از GitHub Secrets و اعتبارسنجی خرید سمت سرور/فروشگاه استفاده شود.
