# ایران؛ سفر در تاریخ و اسطوره‌ها
### Iran Heritage World

یک بازی ماجراجویی سه‌بعدی و برنامه آموزشی اندروید با الهام از تاریخ، تمدن، فرهنگ، اسطوره‌ها و افسانه‌های ایران.

> **وضعیت پروژه: شروع توسعه / MVP** — این مخزن فعلاً اسکلت فنی و نمونه اولیه قابل توسعه را نگه می‌دارد؛ هنوز محصول نهایی یا جهان‌باز کامل نیست.

## هدف نسخه نخست
ساخت تجربه‌ای کوچک اما باکیفیت با عنوان کاری **راز زال و سیمرغ**:
- محیط سه‌بعدی محدود با کنترل سوم‌شخص
- حرکت شخصیت و کاوش محیط
- رابط لمسی اولیه برای موبایل
- پنل یادگیری و محتوای دانشنامه‌ای
- داده محتوایی ساخت‌یافته و قابل گسترش
- خروجی Android APK با GitHub Actions

## فناوری
- Godot **4.4.1** (نسخه CI ثابت)
- GDScript و Mobile/GL Compatibility renderer
- GitHub Actions برای اعتبارسنجی و ساخت ابری

## ساختار
- `app/`: پروژه Godot، صحنه‌ها، اسکریپت‌ها و preset اندروید
- `content/`: محتوای ساخت‌یافته و منابع پژوهشی
- `documentation/`: طراحی محصول، معماری و اصول صحت تاریخی
- `.github/workflows/`: اعتبارسنجی و ساخت APK

## اجرای محلی
Godot 4.4.1 را نصب و پروژه پوشه `app/` را باز کنید. صحنه اصلی `app/scenes/main.tscn` است.

## ساخت APK
از بخش **Actions** در GitHub، workflow با نام **Build Android APK** را دستی اجرا کنید. APK به‌صورت Artifact در اجرای workflow قرار می‌گیرد. این خروجی برای آزمایش است؛ پیش از انتشار باید امضای release و تنظیمات فروشگاه اضافه شوند.

## اصول محتوایی
تاریخ مستند، روایت ادبی، اسطوره، افسانه و بازآفرینی تخیلی از یکدیگر جدا می‌شوند. زال و سیمرغ در این نسخه شخصیت‌های حماسی شاهنامه‌اند، نه اشخاص تاریخی اثبات‌شده. محتوای تاریخی پیش از انتشار به منبع و بازبینی انسانی نیاز دارد.

برای برنامه اجرایی به [نقشه راه](documentation/roadmap.md) مراجعه کنید.
