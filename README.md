# ایران؛ سفر در تاریخ و اسطوره‌ها
### Iran Heritage World

یک بازی ماجراجویی سه‌بعدی و برنامه آموزشی اندروید با الهام از تاریخ، تمدن، فرهنگ، اسطوره‌ها و افسانه‌های ایران.

> **وضعیت پروژه: نمونه اولیه قابل‌بازی در حال توسعه** — نخستین برش محیطی فصل «راز زال و سیمرغ» در شاخه توسعه پیاده‌سازی شده است. این پروژه هنوز نسخه نهایی یا محصول آماده انتشار نیست.

## قابلیت‌های موجود در نمونه اولیه
- محیط کوهستانی کوچک و رویه‌ای با صخره‌ها، درختان و مسیر خاکی
- دوربین سوم‌شخص و حرکت بازیکن نسبت به جهت دوربین
- کنترل صفحه‌کلید و دکمه‌های لمسی
- مأموریت «ردّ آشیانه» با سه نشانه قابل کشف و جمع‌آوری
- نمایش پیشرفت و پایان مأموریت
- پنل دانشنامه متصل به پایان مأموریت
- تفکیک صریح روایت اسطوره‌ای از تاریخ مستند

محیط و شخصیت فعلی با هندسه ساده ساخته شده‌اند تا حلقه اصلی بازی آزمایش شود؛ هنوز مدل شخصیت، سیمرغ، انیمیشن، صدا و طراحی هنری نهایی نداریم.

## کنترل‌ها
- رایانه: WASD برای حرکت، Space برای پرش، E برای تعامل
- اندروید: دکمه‌های لمسی جهت‌دار و دکمه تعامل

## فناوری
- Godot **4.4.1**
- GDScript و GL Compatibility renderer
- GitHub Actions برای اعتبارسنجی و ساخت ابری APK آزمایشی

## ساختار
- `app/`: پروژه Godot، صحنه‌ها، اسکریپت‌ها و preset اندروید
- `content/`: محتوای ساخت‌یافته و منابع پژوهشی
- `documentation/`: طراحی محصول، معماری، صحت تاریخی و نقشه راه
- `.github/workflows/`: اعتبارسنجی و ساخت APK

## اجرای محلی
Godot 4.4.1 را نصب و پروژه پوشه `app/` را باز کنید. صحنه اصلی `app/scenes/main.tscn` است.

## ساخت APK
از بخش **Actions** در GitHub، workflow با نام **Build Android APK** را اجرا کنید یا تغییرات پوشه `app/` را به شاخه توسعه push کنید. در صورت موفقیت، APK آزمایشی به‌صورت Artifact در اجرای workflow قرار می‌گیرد. این خروجی debug است؛ برای انتشار باید امضای release، تنظیمات فروشگاه و آزمایش روی دستگاه واقعی تکمیل شوند.

## اصول محتوایی
تاریخ مستند، روایت ادبی، اسطوره، افسانه و بازآفرینی تخیلی از یکدیگر جدا می‌شوند. زال و سیمرغ در این نسخه شخصیت‌های حماسی شاهنامه‌اند، نه اشخاص تاریخی اثبات‌شده. محتوای تاریخی پیش از انتشار به منبع و بازبینی انسانی نیاز دارد.

برای شرح دقیق برش قابل‌بازی به [مستند دامنه البرز](documentation/vertical-slice-alborz.md) و برای برنامه اجرایی به [نقشه راه](documentation/roadmap.md) مراجعه کنید.
